# おなら研究所｜記事連動漫画シリーズ対応表

## 共通仕様

各記事の冒頭、結論ブロックの直後に、**「漫画でわかる」**として記事専用の4コマ縦スクロール漫画を配置する。漫画は、アオイの生活上の疑問、モクの観察、ナラの整理、読者が持ち帰る見方、という順で構成する。診断や治療を示さず、食品名・回数・臭いだけで結論を急がないサイト方針を守る。

> 例外として、**「おならはなぜ臭い？」**はすでに全10コマ・2ページの第1話を制作済みであり、同位置に2ページ連続表示する。

## サイト設置仕様

各記事の結論ブロックの直後に、漫画セクションを置く。セクションの見出しは「漫画でわかる」で統一し、各記事に合わせたタイトルと短い導入文を添える。第1話は2ページを連続表示し、その他の記事は4コマ縦スクロール1ページを表示する。各画像には、記事の見方を補う説明文をHTMLとして付与する。
